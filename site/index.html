Understand the boundary

Soft guard, not device lock-down

Rusty Kiosk is a normal Spatial SDK app. It is not Android Home, device owner, managed Shared Mode, or tamper-resistant lock task.

01

Normal launch

Opens the selected app with the guard off. The app behaves as it normally would on the headset.

02

Kiosk launch

Starts a fresh target task and arms the Accessibility watchdog for that explicit app.

03

Intentional Home behavior

The first two distinct Home invocations restore the guarded app. The third within five seconds returns to Rusty Kiosk.

04

Wearer-controlled exit

The guard is inactive inside Rusty Kiosk. Press Home there, or select Exit to Meta Home, to leave normally.

First-time setup

Prepare a new headset

USB-C and Developer Mode are required for initial installation and the setup helper's narrow one-time grant. Rusty Kiosk does not silently enable Accessibility, wireless debugging, the direct link, or local APK installation.

Recommended

Use Meta Quest File Manager

The Windows app installs and confirms both APKs, provisions the same-signer helper, and provides the matching desktop catalogue and tag controls.

Developer route

Use the repository script

Build the project, connect one explicitly selected Quest, and run the serial-scoped provisioning script documented in the source repository.

Read the build and provisioning guide

  1. Enable Developer Mode

    Use Meta's supported account and device flow. Rusty Kiosk cannot enable account-level Developer Mode.

  2. Authorize this computer

    Connect a USB data cable, put on the headset, and approve the USB debugging prompt. Trust only a computer you control.

  3. Install and provision

    Install the main Rusty Kiosk APK and its same-signer setup helper. The helper has no launcher, network access, terminal, or general command surface.

  4. Make each optional choice in-headset

    Open User controls. Enable only the capabilities you want; each control reports its current state and offers a corresponding disable or recovery route.

No terminal app is required. USB-C performs the one-time bootstrap. Meta or Android still owns every protected approval shown to the wearer.

Everyday use

Find, tag, and launch apps

Search everything launchable

Search by displayed name, Android package, or tag. Both official and sideloaded launchable apps can appear.

Use portable tags

Add tags in the panel or edit the JSON tag file outside the app. Changes hotload while Rusty Kiosk is running.

Keep missing entries visible

A name-only tag entry remains searchable and filterable when its app is absent, clearly labeled Not installed.

Choose launch behavior

Normal launch leaves the guard off. Kiosk launch is available only when its Accessibility service is actually enabled.

Type with Meta's keyboard

The search and tag fields use native Android text input inside the Spatial panel. Select either field with a hand or controller pointer.

Adjust passthrough

Natural passthrough is the default. An optional color-banded contour LUT helps reveal scene boundaries without claiming camera edge detection.

Transparent control

Nothing is enabled silently

Accessibility soft guard

Observes package and window transitions only. It does not inspect interface text, click buttons, perform gestures, or block Meta Home. Enable and disable it independently.

Direct PC link

Pairs with Meta Quest File Manager for fixed Kiosk commands, tags, bounded staging, and wearer-confirmed APK sessions without routine ADB. Use a trusted local network or private hotspot.

Wi-Fi ADB

A separate optional maintenance path. Rusty Kiosk can ask Meta to show its approval again after restart, but it cannot approve that prompt for the wearer.

Local APK installer

Android's visible “install unknown apps” setting is wearer-owned. Even after that one-time grant, Android may request confirmation for each package installation session.

Direct mode is bounded, not a remote shell. It accepts only documented operations with expiring authenticated requests and replay protection. Its current HTTP transport is integrity-protected but not encrypted.

Questions

What to expect

Does Kiosk prevent someone from reaching Meta Home?

No. Its deliberate escape sequence returns from a guarded app to Rusty Kiosk, where Home reaches Meta Home normally. The visible exit button does the same.

Why is Kiosk launch unavailable?

The Accessibility watchdog is probably off or the setup helper is not provisioned. Open User controls and check the effective status; normal launch remains available.

Why does an app show as Not installed?

The hotloaded tag file can intentionally retain named apps that are not present on this headset. The entry remains useful for shared catalogues but cannot be launched.

Do I need Wi-Fi ADB after setup?

No for normal Kiosk search, tags, launch, guard behavior, and the optional direct PC link. ADB remains useful for maintenance, diagnostics, unattended batch installs, and recovery.

Can the direct installer silently install everything?

No. It submits a bounded Android PackageInstaller session. Android and Horizon retain the confirmation interface and final authority.
