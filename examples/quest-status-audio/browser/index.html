Facilitator guide

Set up

  1. On Quest, open Quest Status and Audio, start a session and allow the requested Bluetooth access.
  2. On the same network, choose Connect headset and select the Quest. Allow local network access when prompted.
  3. Compare the displayed digits and confirm on both devices.
  4. Check for Connected. Choose Identify headset to play a five-second tone if you need to locate it.

Reset or recover

  1. This browser reconnects to its saved headset when a session is available. Select the headset again if its address changed.
  2. When a session expires, start a new one on Quest. Use Forget headset to remove enrollment from this browser.
  3. If a command's outcome is unknown, check the headset before dismissing the saved request or sending another.
