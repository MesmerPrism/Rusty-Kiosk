Facilitator guide

Set up

  1. On Quest, open Quest Status and Audio and start a Bluetooth session. Allow the requested Bluetooth access.
  2. In this browser, enter the displayed code, choose Pair headset, and select the Quest.
  3. Check for Connected. Choose Identify headset to play a five-second tone if you need to locate it.

Reset or recover

  1. For a dropped connection, pair again with the current code while the headset session is active.
  2. For an expired session or a full reset, stop the old session on Quest, start a new one, and use the new code.
  3. If a command's outcome is unknown, check the headset before dismissing the saved request or sending another.
